Extract JSON from unstructured menu text e.g. website, pdf, or markdown according to a schema that follows below.
Use appropriate skills if available.

Return pure, formatted JSON! Do not output markdown, explanations, or comments.
Adhere to this exact JSON schema strictly:
{{schema}}

Source document language will be mostly German, mixed with food related terms in English, Italian, French, Spanish, Indian, etc.
Input text can be structured in sections, e.g. "Vorspeise", "Nachspeise", "Getränke", etc.
Dishes can have subscript codes for contained allergens, ingredients and additives. Capture these carfully!
Find the associated code legend and use it for menu item tagging described below.

Hard validation rules:
- Root object must be { "menu": [...] } with at least 2 entries.
- menu[0] is metadata and must include "name" and "date-created" (ISO datetime).
- menu[1..] are category sections with an "items" array.
- Every item needs "name", "ingredients", "price"; optional "item-number" is allowed.
- item-number, if provided, must be a string with max 40 characters.
- Within each section, sort items by item-number in increasing numeric order,
  comparing the numbers as integers, NOT as strings: 1,2,10,100 - never the
  lexicographic 1,10,100,2. Items without an item-number keep their position
  relative to their neighbors. Sort even if the source menu lists items out of order.
- Order the sections themselves by their lowest item-number, so item-numbers increase
  across the whole file, even if the source menu orders sections differently.
- price must be a number between 0 and 9999.99 with max 2 decimal places.
- Item names must be unique across all sections (case-insensitive). If the same dish
  appears in several sections (e.g. section "Vegan" a "Beilagen"), disambiguate with
  a short section suffix like "Gemischter Salat (Vegan)" or "Kartoffelsalat (Beilagen)".

Tagging rules:
- Items may include optional user-facing lowercase tags. Omit the tags field when no
  tag applies.
- Use the tag "beverage" for drinks; otherwise omit it.
- Diet/style tags: "vegetarian", "vegan" (items from a vegan section get "vegan" only,
  not "vegetarian"), "spicy" (dishes marked scharf/hot),
  "sweet" (desserts, sweet sides).
- Main-protein tags, one per animal named in the dish name or ingredients:
  e.g. "chicken", "lamb", "pork", "beef", "duck", "fish",
  "seafood" (prawns, shrimp, Garnelen, Jhinga, crustaceans).
- Allergen tags, inferred from ingredients AND from any allergen code legend the menu
  provides (e.g. A1=Weizenmehl, C=Eier, G=Milch, H1-H5=nuts). Allergen codes count even
  when the ingredient text does not mention the allergen:
  - "lactose": dairy such as Sahne, Joghurt, Butter, Ghee, Milch, Käse/Paneer/Hüttenkäse,
    Rahm, Malai, ice cream. Coconut milk (Kokosnussmilch) is NOT lactose.
  - "gluten": wheat/spelt flour, Fladenbrot/Naan/Roti/Bhatura, Teigtaschen, breaded items
    (nuggets). Chickpea flour (Kichererbsenmehl) and lentil flour (Linsenmehl) are
    gluten-free, so batter-fried pakoras and papadam are NOT gluten.
  - "egg": Ei/Eier in the ingredients or an egg allergen code.
  - "nut": Mandeln, Cashew, Walnüsse, Pistazien, Erdnüsse or a nut allergen code.
- If tags are unknown or not useful, omit the tags field. If another optional value is
  unknown, use an empty string or omit it.
